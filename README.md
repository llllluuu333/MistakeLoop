# 错题闭环学习助手（MistakeLoop）

把“做题”和“记忆”连起来的考研学习助手：知识库沉淀学过的模型与代码，错题自动进入复习队列，薄弱点地图告诉你该补哪里。

## 环境要求

- macOS + Xcode 26 或更高版本（推荐）
- 最低支持系统：iOS 17（卡片采用系统原生毛玻璃材质，兼容各版本 Xcode / iOS）
- 无需注册、无需联网，数据保存在本机

## 打开与运行

1. 把 `MistakeLoopApp` 文件夹复制到 Mac 上
2. 双击 `MistakeLoop.xcodeproj` 用 Xcode 打开
3. 选择目标设备（真机或模拟器）
4. 按 `Cmd + R` 运行

> 若首次打开没有看到文件，请先关闭并重新打开工程（Xcode 会自动同步文件夹内的文件）。

## 功能

- **今天**：今日复习队列（知识卡 + 错题重做）、连续学习天数、薄弱点提醒
- **知识库**：按学科组织知识条目（概念 / 公式 / 方法 / 代码 / 案例），运筹优化模型库、代码示例
- **卡片**：新建知识卡与错题，按学科筛选与搜索
- **薄弱点**：错题按知识点聚合排行，已解决清单

复习规则：

- 知识卡：记得 → 3 天后；模糊 → 1 天后；忘了 → 当天再来
- 错题：做对 1 次 → 2 天后；连续做对 2 次 → 已解决（7 天后复习）；还不会 → 明天

首次启动会自动写入一批示例数据（单纯形法、运输问题、中值定理等），方便体验完整流程。

## 工程结构

```
MistakeLoopApp/
├── MistakeLoop.xcodeproj     # Xcode 工程（Xcode 16+ 同步文件夹格式）
└── App/
    ├── MistakeLoopApp.swift  # 入口
    ├── Theme.swift           # 配色
    ├── Models/               # SwiftData 数据模型 + 复习调度
    ├── Services/             # 示例数据
    ├── Root/                 # 四标签壳
    ├── Views/                # 全部页面
    └── Assets.xcassets       # 图标与强调色
```
